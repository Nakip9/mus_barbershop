# МУС — онлайн-запись и кабинет команды

Сайт работает как самостоятельная система онлайн-записи. Клиент выбирает услугу, мастера и свободное время; запись сразу блокирует это окно в общей базе расписания.

## Локальный запуск

Требуется Node.js 24+.

```powershell
cd "C:\Users\User\Desktop\Новая папка\mus-source"
npm install
npm run booking:setup
npm run dev
```

Откройте `http://localhost:3000`. Кабинет команды находится на `http://localhost:3000/staff`.

`npm run booking:setup` создаёт администратора и отдельные учётные записи мастеров. Пароли сохраняются только в `.local/staff-access.txt`. Файл нельзя публиковать или загружать в репозиторий.

## Как работает расписание

- Клиент видит только дни и часы, которые открыты у мастера.
- Забронированное время исчезает из списка свободных окон сразу после записи.
- Отмена записи возвращает окно в расписание.
- Мастер видит только свои записи и может завершить или отменить визит.
- Мастер может открыть «График мастера» в кабинете и изменить рабочие дни и часы.
- Перерыв закрывает выбранный промежуток на конкретную дату.
- Администратор видит расписание всех мастеров и может менять график любого мастера.

Время сайта — местное время Челябинска (UTC+5). Доступна запись на ближайшие 30 дней, с интервалом 15 минут и минимальным запасом 30 минут до визита.

## Настройка мастеров и услуг

Измените `config/booking.json`: имена мастеров, категории, рабочие дни (`0` — воскресенье, `1` — понедельник), часы и цены. После изменения перезапустите сервер. Текущие изменения графика, сделанные в кабинете, хранятся в `.local` и имеют приоритет над базовым файлом.

Для реального запуска установите:

```env
BOOKING_LIVE=true
APP_ORIGIN=https://ваш-домен.example
```

Не добавляйте секреты в `NEXT_PUBLIC_*`. Не публикуйте `.env.local`, `.local` или `staff-access.txt`.

## Vercel Free

Vercel Free подходит для интерфейса и API, но локальная SQLite-база не является постоянным хранилищем в serverless-среде: после нового запуска записи могут исчезнуть. Поэтому текущую SQLite-конфигурацию используйте локально или на обычном Node-сервере с постоянным диском.

Для бесплатного постоянного размещения на Vercel нужен внешний PostgreSQL-сервис (например, бесплатный Neon или Supabase) и отдельный адаптер базы данных. Перед публикацией подключите такой адаптер, задайте `DATABASE_URL` в Vercel Environment Variables и перенесите таблицы `bookings`, `blocks`, `master_schedule`, `sessions` и `rate_limits`. Без этого Vercel можно использовать только для демонстрационного просмотра.

Сборка проекта:

```powershell
npm run build
```

Для Vercel подключите Git-репозиторий, выберите Framework Preset `Next.js`, оставьте Build Command `npm run build`, а затем добавьте переменные окружения. После деплоя проверьте `/`, `/staff`, `/api/booking/catalog` и создание тестовой записи.

## Проверка перед запуском

```powershell
npm run build
npm run lint
```

Для проверки используйте вымышленные имя и телефон. Перед публикацией замените демо-мастеров, проверьте рабочие часы, создайте тестовую запись, отмените её и убедитесь, что окно снова стало свободным.
